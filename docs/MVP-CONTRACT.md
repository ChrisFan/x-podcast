# AIPodcast MVP shared contract

Product name: 夜航 / Night Harbor. Native iOS SwiftUI app, account-backed web studio, PostgreSQL API and TTS worker, MCP tools. Sleep-first dark indigo UI, warm cream text, muted sage accents; no medical claims. No fake ready items or fake progress.

API base: https://alu-designer.pawlpixel.com/podcast/api (MVP isolated path; no reuse of AluminumDesigner auth). Local http://127.0.0.1:3211/podcast/api. Web root /podcast/. Authentication: email + password (minimum 10 characters), opaque Bearer token; server hashes stored tokens. Signup may require invite_code configured by operator. Token from login/register response {token,user:{id,email,display_name}}. Password never logged. API error {detail:string} with appropriate 4xx.

GET /health -> {ok:true,...}; POST /auth/register {email,password,display_name,invite_code?}; POST /auth/login {email,password}; GET /auth/me -> user; POST /auth/logout.

GET /catalog -> {voices:[{id,name,description}],scenes:[{id,name,description}],script_schema:object,defaults:object}. Shared canonical script is scripts/rainy-inn.json version 1: id,title,model,voice,language_type,instructions,mix:{intro_seconds,tail_seconds,fade_out_seconds,ambience_dbfs,seed},segments:[{id,label,text,pause_after_seconds}]. Service owns schema/options/validation. Accept same script with each API.

GET /podcasts -> {items:Podcast[]}; POST /podcasts {script:object,scene:string} creates draft; GET /podcasts/{id} -> Podcast; PATCH /podcasts/{id} {script?:object,scene?:string} only draft/failed/cancelled; DELETE /podcasts/{id} -> {ok:true}; POST /podcasts/{id}/generate {request_id:UUID} queues; POST /podcasts/{id}/cancel -> Podcast; POST /podcasts/{id}/retry {request_id:UUID} queues failed/cancelled. Mutations must check ownership, enforce one active job per podcast, honor request id to avoid duplicate paid work; retry returns existing job if already active.

Podcast = {id,title,scene,voice,status,progress,stage,error?,duration_seconds?,created_at,updated_at,script,playback_position_seconds:float,completed:boolean,download_url?:string,audio_url?:string,narration_url?:string}. status enum: draft,queued,generating,mixing,ready,failed,cancelled. progress: integer 0..100 from actual completed steps. stage: human readable Chinese. Server audio URLs authenticated via Bearer, both stream/range and offline downloads. GET /podcasts/{id}/audio?variant=mix|narration; default mix. DELETE removes library entry and revokes access; worker must not resurrect cancelled/deleted item. POST /podcasts/{id}/progress {position_seconds,completed} -> {ok:true}. GET /podcasts/{id}/events -> {items:[{status,stage,created_at}]} for lifecycle history.

GET /preferences -> {voice,scene,ambience_dbfs,sleep_timer_minutes}; PUT /preferences same -> same. Defaults Serena, rainy-inn, -38, 30. Download cache and sleep timer local to app; progress/prefs sync. Background playback, lockscreen controls, seek +/-15s, timer off/15/30/45/60 and end-of-track.

GET /tokens -> {items:[{id,name,created_at,last_used_at}]}; POST /tokens {name} -> {id,token} only revealed once; DELETE /tokens/{id} revokes. MCP tokens owner-scoped; same API data as Web/app. Never return secrets inside catalog/logs. StdIO MCP uses AIPODCAST_API_URL and AIPODCAST_TOKEN. Remote MCP optional port 3212 at /podcast/mcp (same token). Tools: catalog/schema, prefs, validate_script, create/update draft, list/get jobs, generate/retry/cancel/delete, playback link. Creation should not silently submit paid generation unless user requested generation.

Infrastructure: shared ECS 120.55.99.193. PostgreSQL existing container aluminum-cloud-test-db on localhost:55439, separate aipodcast database and aipodcast_owner/aipodcast_runtime users; pool total <=3, migration owner only. API localhost:3211; shared ports 3210,5190,8080,3000,42121 must remain untouched. Root coordinator owns remote deployment and DB provisioning. Use serial worker, bounded resources. Existing podcast.py API producer usable; root may optimize memory and add MP3 output for 1Mbps egress. Secrets stay .env or /etc/aipodcast/, excluded from repo.

Ownership: app agent owns ios/**. service agent owns server/** and web/** and server dependency files. MCP agent owns mcp/** and skills/**. Root owns deploy/** docs/** acceptance/** and podcast.py / common root files. Do not edit another agent's area; propose contract amendments by message first. This contract is baseline, report deviations immediately.
